Now answer two questions from that list alone. Which of these are apps? And which version of the Pomodoro is the good one?

You know the answers because you made them last week. In three weeks you won’t, and neither will anybody else. A name in a list is not an address.

Today you give each app an address: a folder of its own, with the app’s main file inside it called index.html. That name is the front door - the one every browser opens first without being told to. The field guide has the why if you want it; this lab is the doing.

It takes about fifteen minutes and there is no code in it at all. It is the last quiet lab for a while.

Inside vibe-coding, make four new folders. Name them exactly like this - all lowercase, hyphens instead of spaces:

  • qr-code
  • hello
  • pomodoro
  • countdown

If you named your apps something else last week, name the folders after your files instead. The rule is one folder per app, not these four words.

Why lowercase with hyphens? Because a folder name becomes part of a web address later, and addresses are fussy about capitals and hate spaces. You are building the habit now, while it costs nothing.

One app at a time. For the QR code generator:

  1. Drag qr-code.html into the qr-code folder.
  2. Open the folder. Rename the file to index.html. On a Mac, click the name once, then press Return. On Windows, right-click and choose Rename.
  3. Keep the .html on the end. If your computer asks whether you are sure you want to change the extension, you are not changing it - it was .html before and it is .html now. Say keep.

Then do the same for the other three. Three minutes, once you have the rhythm.

When you are done you will have four files called index.html on your computer, and that is correct. They do not collide, because each one lives at a different address. qr-code/index.html and countdown/index.html are as different as two houses with the same color front door.

Some of your apps have a -v1 file beside them - the copy you made before letting the AI change something that worked. Those belong with their app.

Move pomodoro-v1.html into the pomodoro folder and rename it index-v1.html. Same for countdown-v1.html.

The pattern from here on: the app you are using is always index.html, and its history sits beside it with a version number on the end.

Leave setup-check.html where it is, loose in vibe-coding. It isn’t an app - it was a scrap of paper that proved your editor worked. Not everything needs a folder.

Double-click each index.html in turn. All four should open and work exactly as they did last week: the QR code generates, the timer counts, the countdown counts.

Notice that nothing broke. You moved every file on your computer and all four apps still work perfectly. That is worth a moment, because it is about to stop being true.

Each of those apps is one file that needs nothing else. It can go anywhere. In the very next lab you build a page that needs a photo sitting beside it, and from then on where a file lives is something your apps care about.

My browser says the file can’t be found

You have a tab open from last week that still points at the old location, and the file isn’t there any more. That is the tab being out of date, not the file being broken. Close the tab and double-click the new index.html instead. From now on, open apps from the folder.

It asked if I really want to change the extension

Say keep .html. The file was qr-code.html and it is becoming index.html - the extension is not changing at all, your computer is just being careful because you retyped the whole name. If you accidentally ended up with a file called index with nothing on the end, rename it again and type index.html in full.

I can’t see the .html part of any name

Extensions are hidden again, which makes this lab nearly impossible to do correctly. Turn them back on the way you did in the setup lab: on a Mac, Finder → Settings → Advanced → Show all filename extensions. On Windows, File Explorer → View → File name extensions. Then come back.

Now I have four files called index.html and I’m lost

That is the right answer, oddly enough. The file name stopped being the app’s name the moment it got a folder - the folder is the name now. When you are looking at an open file and can’t tell which app it is, look at the folder it is in, or look at the tab title in the browser.

I dragged something into the wrong folder

Command + Z on a Mac, Control + Z on Windows, right there in the folder window. Undo works on file moves, and almost nobody knows it. If the undo has gone stale, just drag it back - nothing is damaged by being in the wrong place.

Which -v1 is the good one?

index.html is always the one you are using. index-v1.html is the older version you kept as a safety net before an iteration. If you open both and the -v1 is the one you like better, rename them the other way round - that is exactly what the safety net is for.
