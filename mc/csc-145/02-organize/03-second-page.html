Your recipe card is one page. Some things don’t belong on it: where the recipe came from, what you changed, the time you doubled the salt by accident. That is a second page.

This lab is short, and it contains one genuinely new move: the AI is going to hand you two code blocks, and you are going to make two files. Every build until now has been one block, one file, paste over everything. Today that habit is a trap, and the Run it step tells you exactly where.

Go back to the same chat you built the recipe card in - it still knows what your page looks like. Ask for:

  • A link on the recipe page to a second page called notes.html
  • The second page built too, in the same style, with room for a few paragraphs about the recipe
  • A link on that page going back to index.html
  • Both files as two separate code blocks, each one labelled with its file name
  • Everything else kept exactly as it is

That fourth line matters. Ask for one block and you will get two pages glued into one file, or one page and a description of the other. Ask for two labelled blocks and you get two things you can copy one at a time.

You do not need the specification again - the AI is still working inside it from the last build. If you started a fresh chat, paste it back in.

Read this whole step before you touch anything. This is the one place in the chapter where a wrong move costs you work.

  1. The first block is index.html. Copy it, open your existing recipe/index.html in TXTEDTR, paste over everything, save. Same as always.
  2. The second block is a new file. Copy it, and in TXTEDTR make a new, empty document first. Paste. Then Save as notes.html, in the recipe folder.
  3. Open index.html in your browser. Click the link. You should land on the notes page. Click the link there. You should come back.

The trap: pasting the second block over the file you still have open. Then index.html contains the notes page, your recipe card is gone, and the link goes nowhere. It happens to plenty of people the first time. If it happened to you, the first Troubleshooting card gets it back.

In index.html, find the link. It starts with <a. What is inside the quotes, and what is between the tags?

Something like <a href="notes.html">My notes on this</a>. Inside the quotes is where it goes, and that is for the browser. Between the tags is what you click, and that is for the person. Two separate things that have nothing to do with each other.

Now look at the link on notes.html. What is in its href?

index.html. The front door, by name. Two pages, each holding the other’s name, and that is all a link between pages has ever been.

Why doesn’t either link mention the recipe folder?

Because they are already in it. A page looks for a name in its own folder first, exactly the way photo.jpg was found. Same address, so a name is enough. Pointing at a file in a different folder needs more, and that is a later chapter.

Change what the link says without changing where it goes.

In index.html, find the link and edit only the words between <a ...> and </a>. Make it sound like you: Why mine has more garlic, The story, Read this before you make it. Leave everything inside the quotes alone.

Save, refresh, click it. It still goes to the same place. You changed the label on the door, not the door.

Save copies first: index-v1.html and notes-v1.html.

I pasted the second block over my recipe card and lost it

Fixable, and you have two routes. If you made index-v1.html in the last lab, open it, copy everything, and paste it back into index.html - you lose only the link. Otherwise go back to the chat: the recipe card is still sitting there in the AI’s earlier reply, and you can say “show me index.html again as a code block.” Nothing you have made is ever only in one place, as long as the chat is still open.

I click the link and get a page-not-found error

Look at the address bar. The end of it is the name the browser went looking for. Now look at the file in your folder. One of them is wrong - usually a capital letter, or note.html against notes.html, or the file is sitting somewhere other than the recipe folder. Make them match.

The link goes one way but not back

The return link is missing or points at the wrong name. Open notes.html and look for <a. If there is no link at all, ask the AI: “add a link at the top of notes.html going back to index.html.” If it is there, check what is inside the quotes.

I only got one code block

Ask again, specifically: “give me two separate code blocks, one for index.html and one for notes.html, each labelled with its file name.” If it put both pages inside one file instead, say: “these need to be two separate files that link to each other.” Being precise about what shape you want back is a skill, and this is a good place to practise it.

The two pages don’t match each other

The AI rebuilt the styling from memory rather than copying it. Tell it: “make notes.html use exactly the same styles as index.html - same fonts, same colors, same card.” If they still drift apart, that is a real limitation of one file per page, and it is one of the reasons the course eventually stops doing everything this way.

My photo disappeared from the recipe page

When the AI rewrote index.html it may have changed the src or dropped the <img> tag. Check that src still says photo.jpg. This is worth noticing: asking for one change can quietly alter something else, which is why keep everything else the same is in every prompt you write.
