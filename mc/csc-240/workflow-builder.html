Workflow Builder

Build an AI workflow from steps, run it on a real message, and watch every handoff - then take it with you as instructions and a picture. No account, no key, and nothing ever leaves this page.

What this is

Tools like Copilot Studio, Power Automate and Zapier let you build workflows like this: something arrives, AI steps sort it and pull details out of it, a person checks the work, and something gets sent. This is a practice version, laid out like the Copilot Studio designer you are most likely to meet at work.

  • Build: pick steps from Add on the left. They land on the canvas. Click any step to change its settings on the right.
  • Test: give it an item - an email, a request - and watch each step on the canvas turn green, wait for you, or fail.
  • Activity and Monitor: what happened in the last test, step by step - and every test so far, with everything it “sent”.
  • Agents with tools: give an Agent step tools - look something up, search, send - and it decides which to use. Each tool can ask a person first, or just do it.
  • Export: download workflow.md (instructions an AI builder can follow, plus a diagram) and a picture of the workflow.

Try this first

  1. Press Test, pick the sample Question and press Run the test. Approve the reply when Rosa’s review comes up. Open Monitor and find it in the Outbox.
  2. Run the same email again. Two replies in the Outbox - the same person emailed twice. Click Start on the canvas, tick Run once per item, and try again.
  3. Test Someone hurt and Doesn’t fit. One takes the True path; one fails. Where did each one go, and who found out? Activity has the details.
  4. Now load the example Front desk agent, with tools (click Start, then Examples). One agent, four tools hanging off it on dotted lines - and it picks which to use. Test all five samples. Which tool acts without asking? Should it? And read what Doesn’t fit nearly sent.
The “AI” here is two different things

Stand-in rules are not AI at all: Classify matches the words you list, Extract looks for patterns like email addresses, Agent fills in the {braces} in your instructions. They are simple on purpose, so you can focus on the wiring - and they make mistakes, which is what review steps and failure paths are for.

My own AI chat uses real AI. At each AI step you get the exact prompt to paste into any AI chat, then you paste the answer back. Only paste items you would be comfortable sharing with that AI tool.
